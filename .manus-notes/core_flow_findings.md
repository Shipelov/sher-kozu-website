# Core Flow Findings

Источник: `/home/ubuntu/projects/shercozu-13761765/Шерь_Козу_Маркетинговое_исследование_и_стратегия.pdf`.

Предварительные выводы по просмотренным страницам исследования:

1. Продукт позиционируется не как обычный ecommerce фермы, а как сервис персонального фермерства и lifestyle membership.
2. Ключевая ценность — эмоциональная связь семьи с конкретным животным, прозрачность происхождения молочной продукции и клубный опыт.
3. Core flow должен фокусироваться на пути: главная страница → галерея/выбор животного → профиль животного → выбор доли/вовлечение → клуб/личный кабинет/продуктовый трекер.
4. Админские и интеграционные разделы важны, но должны развиваться как поддерживающий операционный слой, а не как главный продуктовый приоритет.
5. Roadmap следует делить не по техническим подсистемам, а по продуктовым контурам: acquisition, conversion to share, ownership experience, farm operations.
