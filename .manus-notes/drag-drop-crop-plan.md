# План внедрения drag-and-drop и кадрирования

Цель текущего шага — улучшить загрузку фото в `AnimalProfile.tsx` без изменения серверного контракта.

## Подход

Нужно реализовать клиентский поток в три стадии. Сначала пользователь либо перетаскивает изображение в dropzone, либо выбирает его через файловый input. Затем перед фактической загрузкой открывается простой экран кадрирования. После подтверждения кадрирования на сервер отправляется уже обработанная версия изображения в текущий `animalPhotos.upload` маршрут.

## Ограничения

Серверную часть лучше не менять без необходимости, так как текущий backend с БД и S3 уже стабилен и покрыт тестами. Основные изменения должны быть сосредоточены в `client/src/pages/AnimalProfile.tsx`.

## Планируемые изменения

Нужно добавить локальное состояние для:

- drag-over состояния dropzone;
- очереди выбранных файлов;
- текущего файла для кадрирования;
- превью изображения до сохранения;
- параметров простого кадрирования.

Нужно добавить простую реализацию кадрирования через canvas без новых тяжёлых зависимостей, если это возможно в разумном объёме.

## UX-результат

Пользователь должен получить:

- заметную dropzone в галерее;
- понятный переход к кадрированию;
- подтверждение перед сохранением;
- сохранение существующего сценария через обычный input;
- отсутствие регрессии в удалении фото и истории действий.
