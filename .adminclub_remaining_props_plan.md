# AdminClub remaining tabs refactor plan

## Goal
Вынести вкладки `bitrix` и `activity` из `AdminClub.tsx` в отдельные presentational-компоненты по образцу `adminClubCrudTabs.tsx`, оставив state, trpc и URL-sync в контейнере.

## Bitrix tab: main blocks
1. Executive / monitoring summary cards
2. Leads filter toolbar and paginated lead list
3. Selected lead detail view with timeline, payload and retry/snapshot history
4. Global Bitrix audit trail list

## Activity tab: main blocks
1. Header actions: collapse, copy link, export scope, CSV, clear log
2. Preset toolbar and sticky filter summary
3. Stats cards for action types and areas
4. Critical notifications settings card
5. Critical notifications history card
6. Grouped session action log / empty state
