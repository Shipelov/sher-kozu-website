# Дизайн единого RAG-поиска Зои

## Цель

Оба chat-пути — tRPC `nutritionist.chat` и SSE `/api/zoya/chat/stream` — должны вызывать один helper, который принимает исходный пользовательский вопрос и возвращает не более шести активных релевантных записей. Публичный `nutritionist.knowledge.search` использует ту же search-функцию.

## Нормализация запроса

Текст приводится к нижнему регистру, `ё` заменяется на `е`, дефисы и пунктуация становятся пробелами. Удаляются стоп-слова и общие вопросительные слова. Значимые слова приводятся к устойчивым поисковым основам с помощью консервативного удаления русских окончаний. Короткие предметные токены `A2`, `B2`, `B12`, `pH`, `CLA`, `MCT` сохраняются.

## Candidate selection

База выбирает только записи `status=active`. Для каждого нормализованного термина используется OR-поиск по `title`, `content` и сериализованному JSON-полю `tags`. Количество кандидатов ограничивается защитным лимитом, превышающим итоговый `limit`, чтобы ранжирование выполнялось в памяти без полного чтения таблицы.

## Scoring

Результат получает баллы за совпадения уникальных терминов: наибольший вес у заголовка, затем у тегов, затем у содержания. Дополнительно учитываются доля покрытых терминов, точная нормализованная фраза, `confidence` и свежесть. Результаты, совпавшие только по слишком общему слову, не должны вытеснять записи с несколькими предметными совпадениями.

## Защита от дублей и шума

После сортировки выдача дедуплицируется по нормализованной паре `title + content`. При равных score приоритет получают более высокая уверенность, более свежая дата и меньший ID как стабильный tie-breaker. Пустые запросы возвращают пустой массив без обращения к базе.

## Тесты

Регрессии покрывают кальций и белок овечьего молока, A2/казеин/аллергию, лактозную непереносимость, козий сыр и микробиом. Дополнительно проверяются порядок слов, словоформы, стоп-слова, пустой запрос, неактивные записи, дедупликация, лимит и единое подключение helper к tRPC и SSE.
