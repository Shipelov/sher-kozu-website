# Шерь Козу — Персональное фермерство

Веб-платформа для семейной фермы «Шерь Козу», реализующая модель персонального фермерства: долевое владение животными, трекинг продукции от надоя до доставки, клубная экосистема и AI-ассистент.

## Концепция

«Шерь Козу» — это не магазин фермерских продуктов. Это экосистема, в которой семья выбирает конкретное животное (козу или овцу), приобретает долю участия и получает именные молочные продукты с полной прозрачностью происхождения. Платформа объединяет:

- **Каталог животных** с профилями, галереями и историей каждого животного
- **Долевое владение** — выбор доли от 10% до 100% с прозрачным ценообразованием
- **Трек продукции** — от надоя до доставки, включая выбор продуктового плана (молоко, сыр, йогурт, кефир, сметана)
- **Кабинет владельца** — дашборд с текущим животным, графиком доставки и дневником фермы
- **Клубная лента** — события, мастер-классы, визиты на ферму
- **AI-ассистент «Маша»** — консультации по продуктам и ферме
- **Игровая экономика** — токены SKC за активность в экосистеме
- **CMS с версионированием** — 47+ редактируемых блоков главной страницы

## Технологический стек

| Слой | Технологии |
|---|---|
| Frontend | React 19, Tailwind CSS 4, shadcn/ui, Framer Motion, Wouter |
| Backend | Express 4, tRPC 11, Superjson |
| База данных | TiDB Cloud (MySQL-совместимая), Drizzle ORM |
| Аутентификация | Manus OAuth + локальная регистрация (email/телефон + пароль) |
| Хранилище | AWS S3 (через Manus Storage) |
| Тестирование | Vitest (2271 тестовый блок, 85 файлов) |
| AI | LLM-интеграция для FAQ-чата и ассистента |
| CRM | Bitrix24 (лиды, сопровождение семей) |

## Переменные окружения

Все секреты управляются через платформу Manus и инжектируются автоматически. В коде нет захардкоженных ключей.

| Переменная | Описание |
|---|---|
| `DATABASE_URL` | Строка подключения к TiDB Cloud |
| `JWT_SECRET` | Секрет для подписи сессионных cookie |
| `VITE_APP_ID` | ID приложения Manus OAuth |
| `OAUTH_SERVER_URL` | URL сервера OAuth |
| `BITRIX24_BASE_URL` | Базовый URL Bitrix24 |
| `BITRIX24_REST_USER_ID` | ID пользователя REST API Bitrix24 |
| `BITRIX24_WEBHOOK_TOKEN` | Токен вебхука Bitrix24 |
| `BUILT_IN_FORGE_API_URL` | URL встроенных API Manus (LLM, S3, уведомления) |
| `BUILT_IN_FORGE_API_KEY` | Ключ для серверных API Manus |

## Запуск

### Предварительные требования

- Node.js >= 22
- pnpm

### Установка и запуск

```bash
# Установка зависимостей
pnpm install

# Применение миграций БД
pnpm db:push

# Запуск dev-сервера
pnpm dev

# Запуск тестов
pnpm test
```

Dev-сервер запускается на `http://localhost:3000/`.

## Тестирование

Проект покрыт 2271 тестовым блоком в 85 файлах. Тесты охватывают:

- Серверные роутеры (CRUD, авторизация, валидация)
- E2E сценарии (галерея → профиль → выбор доли → бронирование → дашборд)
- Безопасность (отсутствие plainPassword, защита admin-маршрутов)
- Компоненты (ShareSelectionPreviewCard, карточки животных)
- Регрессии Phase D (auth flow, admin guards)

```bash
pnpm test          # Запуск всех тестов
pnpm test -- --reporter=verbose  # Подробный вывод
```
