# Анализ пути нового клиента (неавторизованного)

## Текущее состояние

### Навигация (Navbar.tsx)
- Для неавторизованных: показывает только "Главная", "Каталог животных", "Клуб" + кнопку "Войти"
- "Мой кабинет" и "Трекер продуктов" скрыты для гостей — ОК
- Кнопка "Войти" ведёт на getLoginUrl("/dashboard") — после входа перенаправляет в дашборд
- В мобильном меню тоже есть кнопка "Войти" — ОК

### Главная страница (Home.tsx)
- НЕТ кнопки "Войти" или "Зарегистрироваться" на самой странице
- CTA кнопки: "Открыть галерею", "Открыть профиль Мира", "Открыть дашборд владельца", "Стать партнёром"
- "Открыть дашборд владельца" ведёт на /dashboard — для неавторизованного это проблема (может перенаправить на логин или показать пустой экран)
- "Перейти в кабинет" в footer тоже ведёт на /dashboard

## Проблемы
1. На главной нет явного CTA "Стать участником" / "Зарегистрироваться" для нового клиента
2. Кнопка "Открыть дашборд владельца" для неавторизованного пользователя не имеет смысла — нужно либо скрыть, либо заменить на "Войти/Зарегистрироваться"
3. Путь нового клиента: Главная → Каталог → Выбор животного → Покупка доли — на этапе покупки нужна авторизация, но нет явного указания
4. Кнопка "Войти" в навбаре — единственная точка входа для регистрации, но она не бросается в глаза

## Рекомендации
1. Добавить на главную CTA "Стать участником" или "Начать знакомство" с ведением на логин
2. Заменить "Открыть дашборд владельца" для гостей на "Войти и начать" 
3. В footer заменить "Перейти в кабинет" для гостей на "Войти"
