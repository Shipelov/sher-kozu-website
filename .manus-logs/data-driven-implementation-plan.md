# План перехода на реальные данные

Для Product Tracker логично ввести таблицы продуктовых партий, месячных показателей состава и доставок, связанные с animalSlug и ownerOpenId. Это позволит заменить локальные массивы `composition`, `monthlyData` и `deliveries` на данные из базы, сохранив текущий сторителлинг и activeDelivery как состояние интерфейса поверх ответа tRPC.

Для Club Feed стоит добавить таблицы клубных постов, событий и участников с лёгкой seed-структурой для владельца. На сервере потребуются helper-функции чтения и публичные либо защищённые процедуры tRPC, а на клиенте — замена демо-массивов на `trpc.*.useQuery()` с корректными loading и empty state.

Следующим практическим шагом будет расширение `drizzle/schema.ts`, затем `server/db.ts`, после этого `server/routers.ts`, обновление страниц и обязательные vitest smoke-тесты для новых data-driven маршрутов.
